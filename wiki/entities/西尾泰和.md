# 西尾泰和（にしお ひろかず）

本プロジェクトの著者。1981年生まれ。サイボウズ・ラボ主幹研究員、一般社団法人未踏 理事、未踏ジュニア ファウンダー兼メンター。

## プロジェクトでの役割

- 本書の単独著者。LLM との対話相手・最終決定者。
- 既存の「[エンジニアの知的生産術](エンジニアの知的生産術2018.md)」（2018）と「[コーディングを支える技術](コーディングを支える技術2013.md)」（2013）を発展させる立場。
- [Kozaneba](Kozaneba.md) の開発者。
- 7年で約2万記事を蓄積した [Scrapbox](Scrapbox.md) ユーザー。

## 関心領域

- 個人とチームの **知的生産性** の研究と実践。
- プログラミング言語の進化と知的生産の関係。
- LLM 登場後は「LLM をパートナーとした知的生産」の最前線。
- [デジタル民主主義](デジタル民主主義.md)（2024年中の主軸プロジェクト。本書プロジェクトと並走）。集団における知的生産性向上の手段としての **ブロードリスニング** 研究を含む。

## システム理解力の系譜（[Day 12](../timeline/Day12.md) Session A で提起、Session C で集団スケールを追加）

著者は自身の関心の発展を以下のように整理している：

1. **プログラムの挙動の理解** — 元々持っていたシステム理解力の最初の発揮先。
2. **プログラミング言語** — 「複雑なプログラム」の実例として、システム理解力が言語そのものに発揮される。
3. **プログラミング言語の発展の歴史** — さらに射程を広げ、社会的相互作用のシステムまで視野に入れる。これが [コーディングを支える技術](コーディングを支える技術2013.md) (2013) になった。
4. **執筆という知的生産そのものをメタな自分が観察** — 知的生産の作業を観察して生まれたのが [エンジニアの知的生産術](エンジニアの知的生産術2018.md) (2018)。
5. **LLM 普及後の個人の知的生産** — 本書 LENCHI は、上記 4 の対象を **LLM との対話を含む知的生産** に拡張したもの。著者は「実際に使ってみて観察し、観察結果から理解を深める」方針を取る。**「過去に良かった方法」に固執して「新しいより良い方法」を発見できなくなる心理**（[利用と探索のトレードオフ](https://scrapbox.io/nishio/利用と探索のトレードオフ)）への自己警戒を含む。
6. **集団の知的生産へ** — 同じ問題関心を **集団スケール** に展開した系譜：
   - **2018 [階層組織](https://scrapbox.io/nishio/階層組織)** — 「人間にはコミュニケーションを取れる人数に限界がある」ため階層が生まれる
   - **2019 [個人情報とマネタイズ](https://scrapbox.io/nishio/個人情報とマネタイズ)** — ボトルネックは「人間の情報伝達能力」ではなく「**人間の情報処理能力**」
   - **2023-03 [LLMがもたらす組織構造の変化](https://scrapbox.io/nishio/LLMがもたらす組織構造の変化)** — ChatGPT リリース後、「これが懸案の課題を解決する技術じゃん！」と認識
   - **2023-04 [Plurality Tokyo 2023](https://scrapbox.io/nishio/Plurality_Tokyo_2023)** — Pluralityで「[ブロードリスニング](../concepts/ブロードリスニング.md)」概念に出会い、自分の系譜と接続
   - **2023-08 [主観か客観かではなく、一人の主観から大勢の主観へ](https://scrapbox.io/nishio/主観か客観かではなく、一人の主観から大勢の主観へ)** — 情報処理学会誌寄稿、「あの図」言語化
   - **2024-05** — [デジタル民主主義](デジタル民主主義.md) の好機到来、LENCHI を一旦傍に置いて社会実装側へ

「**人間の情報処理能力のボトルネック**」という同一の問いが、**個人スケール（LENCHI）** と **集団スケール（[ブロードリスニング](../concepts/ブロードリスニング.md) / デジタル民主主義）** の二系統で展開している。これは LENCHI の中断と再起動を整合的に説明する。

# ChatGPT / GPT-4 / GPT-4o

OpenAI 製の LLM サービス群。**※本ページは Day1〜10（2024）期の観察記録**。GPT-4 / GPT-4o / o1 / o1 pro までを扱う。プロジェクト休止中（2024-12〜2026-04）の後続モデル（GPT-5 系等）は未反映、[未解決の問い Q12](../questions/未解決の問い.md) で扱う。

## プロジェクトでの役割

- 著者は ChatGPT のカスタムGPT 機能を使い、自身の Scrapbox をベクトル検索する **[NISHIOアシスタント](NISHIOアシスタント.md)** を構築・公開。
- GPT-4 を使った対話では、検索のたびに大量の情報がコンテキストに流入し、**過去の発言を忘れて脱線** する傾向が観察された（[Day6](../timeline/Day6.md)、[コンテキスト維持](../concepts/コンテキスト維持.md)）。
- GPT-4o による [Kozaneba](Kozaneba.md) 画像認識を試したが、解像度の問題でマインドマップの読み取りに限界。

## 対比

- 長文の文脈維持・収束 → [Claude 3 Opus](Claude3Opus.md) の方が得意。
- 著者: 「GPT は外面だけ見ると話が脱線しまくってころころ変わる人のような雰囲気がある。Claude と話す方が心の安寧がある」。
- 一方で **発散的思考** という意味では GPT-4 の脱線にも価値がある（カスタム GPT が「3つの学び方」と関連付ける発想を出した）。
